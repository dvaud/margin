# Add-on API

An app built on Margin documents the routes it adds here, in the form of `docs/API.md`: a heading per route, with the
route written as `` `GET /api/...` ``. The tests that check every route is documented read this file as well as
`docs/API.md`.

Margin on its own adds no routes here.
